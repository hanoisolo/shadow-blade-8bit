## Game Concept & Controls
- Retro 8-bit/16-bit dark-fantasy side-scrolling hack-and-slash set on a
  gothic moonlit stone bridge.
- Classic NES controls: Left/Right movement + Two Action Buttons:
  1. HACK (`KeyZ` / `KeyJ` / `#btn-hack`): Swings warrior's broadsword with
     active attack frames, hitbox reach, cooldown frames, and hit-stop impact.
  2. JUMP (`Space` / `KeyK` / `#btn-jump`): Parabolic jump with gravity
     (`vy`, `GRAVITY`, `GROUND_Y`), allowing air-slashes and dodging enemy
     attacks.

## Segment 1 (`hackslash_engine.js` + `test_hackslash.js`)
- Pure JS dual UMD module (`window.HackSlashEngine` for browser,
  `module.exports` for Node).
- Exact exported constants and pure functions:
  1. `GAME_CONFIG`: Stage dimensions (`width: 800`, `height: 450`,
     `groundY: 360`, `gravity: 0.65`), Hero base stats (`maxHp: 100`,
     `speed: 4.5`, `jumpForce: -13.5`, `attackDamage: 25`, `attackRange: 68`,
     `attackDurationFrames: 14`, `attackCooldownFrames: 20`,
     `invulnFrames: 30`).
  2. `ENEMY_TYPES`:
     - `goblin`: Fast scout (`maxHp: 30`, `speed: 3.2`, `damage: 8`,
       `width: 44`, `height: 48`, `scoreValue: 100`, `attackRange: 36`).
     - `skeleton`: Undead swordsman (`maxHp: 60`, `speed: 2.0`, `damage: 14`,
       `width: 48`, `height: 64`, `scoreValue: 250`, `attackRange: 48`).
     - `ogre`: Giant horned boss (`maxHp: 220`, `speed: 1.1`, `damage: 28`,
       `width: 96`, `height: 112`, `scoreValue: 1000`, `attackRange: 76`).
  3. `STAGE_WAVES`: 3 waves in the single stage (Wave 1: Goblins &
     Skeletons; Wave 2: Skeletons & Goblins; Wave 3: Giant Ogre Boss +
     minions).
  4. `createInitialState(options)`: Returns clean mutable game state
     (`hero`, `enemies`, `particles`, `wave`, `score`, `combo`,
     `status: 'playing' | 'victory' | 'gameover'`, `frameCount`).
  5. `stepHeroPhysics(hero, input, config)`: Updates horizontal velocity,
     clamps stage bounds (`0` to `config.width`), applies jump velocity if
     grounded, applies gravity, resolves landing on `groundY`, and advances
     `animState` (`idle`, `run`, `jump`, `hack`, `hurt`) and `animFrame`.
  6. `performHeroHack(state, config)`: Triggers hero hack state if cooldown
     is 0, checks AABB / reach hitbox intersection against all living enemies
     in facing direction, applies damage, knockback velocity, increments
     combo & score, and removes defeated enemies.
  7. `stepEnemiesAI(state, config)`: Moves each living enemy (`goblin`,
     `skeleton`, `ogre`) toward the hero, triggers enemy attack
     windup/strike when within `attackRange`, applies damage to hero if hero
     `invulnTimer === 0`, and advances wave or sets `status: 'victory'` when
     all waves are cleared or `status: 'gameover'` if `hero.hp <= 0`.
  8. `createSampleBossBattleState(config)`: Returns a pre-populated mid-action
     demo state on Wave 3 featuring the Hero alongside 1 `skeleton`,
     1 `goblin`, and 1 `ogre` boss with active score/combo for 1-click
     testing via `#btn-load-sample`.
- `test_hackslash.js`: 35+ headless Node `assert` unit tests verifying hero
  jump physics, gravity landing, stage boundary clamping, hack hitbox
  detection (facing left vs. right), cooldown enforcement,
  goblin/skeleton/ogre stat invariants, enemy AI damage & invulnerability
  frames, wave progression, victory/gameover transitions, and sample boss
  state generation.
- Segment gate: `node --check hackslash_engine.js` then
  `node test_hackslash.js` (all 35+ tests pass).
